# txt-to-word-converter

Modern TXT to Word converter built with Next.js App Router, TypeScript, Tailwind CSS, ESLint, and the `src/` folder structure.

Convert plain `.txt` content into downloadable Word `.docx` files directly in the browser.

## Live Demo

To view the live tool, please visit: [TXT to Word Converter](https://aslitools.com/tools/txt-to-word)

## Stack

- Next.js 16
- React 19
- Tailwind CSS 4
- TypeScript 5
- ESLint 9

## Clone and Use

Clone the repository:

```bash
git clone https://github.com/your-username/txt-to-word-converter.git
```

Go into the project folder:

```bash
cd txt-to-word-converter
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

Create a production build:

```bash
npm run build
```

Start the production server:

```bash
npm run start
```
